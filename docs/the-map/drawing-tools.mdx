# Drawing Tools & Symbols

Use the drawing toolbar at the bottom of the map to add shapes, lines, text, and military symbols. Drawings can be personal or shared with everyone who can view the publish.

## Who Can Draw

Editors can add shared drawings. Other users can be granted shared drawing access via the [Drawing Access Rules](../creating-a-frag-order/managing-access#drawing-access-rules) in the Access tab. New shapes, symbols, and text start on your **Personal** layer; switch to **Shared** in the drawing details when you want others to see them.

## Drawing Tool Toolbar

The toolbar at the bottom of the map contains the following tools:

| Tool | Description |
|------|-------------|
| **Pointer** | Select and move existing drawings |
| **Line** | Draw a straight line or multi-segment polyline |
| **Route** | Plan a flight route of numbered waypoints (see [Planning a Route](../planning/dtcs#planning-a-route)) |
| **Rectangle** | Draw an axis-aligned rectangle |
| **Circle** | Draw a circle (drag from center) |
| **Polygon** | Draw a free-form closed polygon |
| **Symbol / Icon** | Place a military unit symbol marker |
| **Text** | Place a text annotation with multiline content, size, outline, and rotation |
| **Freehand** | Draw a freehand line |
| **Eraser** | Delete a drawing by clicking it |

## Creating a Shape

Select a shape tool, then click on the map to place vertices. For polygons, each click adds a vertex — double-click or close the shape to finish.

## Editing a Drawing

Click any existing drawing to open its details popover. From here you can:

![Drawing details popover — shape](/img/drawing_details.png)

- **Name** — give the drawing a label that appears on the map
- **Stroke** — set the outline color
- **Fill** — set the fill color, or clear it for an outline-only shape
- **Altitude** — optionally attach an altitude value
- **Delete** — remove the drawing entirely

The popover also shows the centroid coordinates in both decimal degrees and MGRS.

The **Route** tool plans a flight route of numbered waypoints and writes it into an aircraft's Data Transfer Cartridge — see [Planning a Route](../planning/dtcs#planning-a-route).

## Text Annotations

1. Select **Text** in the drawing toolbar and click the map to place an annotation.
2. Select it and replace **Text** with your content. You can enter multiple lines; changes save when you leave the field.
3. Set **Size (px)**, **Outline (px)**, and **Angle (°)**. An outline of `0` removes the text-box border; positive angles rotate clockwise. **Stroke** sets the text color and **Fill** sets the background.

Text stays the same display size as you zoom in either the 2D or 3D map. Move an annotation with the selection tool, or save it in the [Drawing Library](drawing-library) to reuse its content and styling.

To include text on the DCS F10 map, make the drawing **Shared** and choose a **Miz Layer** under **Export Targets**. Packaged missions contain native DCS text boxes with the annotation's styling. Text has no DTC export target.

## Military Symbols (Icons)

Selecting the **Symbol** tool places a NATO MILSYM-style icon marker. Click the drawing to open its popover and choose from the available symbol types:

![Icon drawing with symbol picker](/img/drawing_icon.png)

Available symbols include Infantry, Armor, Artillery, Air Defense, Recon, and HQ / Command Post, among others. Give the marker a name and it will display as a label on the map.

You can also enter any **SIDC** (Symbol Identification Code) directly to place any NATO APP-6 symbol. Use [milsymb.net](https://sidc.milsymb.net/#/APP6/10061000001205000000) to browse and build SIDC codes for any unit type.
