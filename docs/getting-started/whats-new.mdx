# What's New in v2

v2 is a ground-up rewrite of Frag Orders with a new backend, a new map engine, and a significantly expanded planning model. Here's what's changed.

## Redesigned Access Control

Access rules now support Discord roles directly alongside individual users, and multiple users or roles can be assigned to the same flight group as planners. Assign `@Squadron` as a planner for a flight and everyone with that role gets access automatically. Stack a flight lead on top of that and both can plan the same package independently — the most requested feature from v1.

![Group access with multiple planners and signup rules](/img/signupsaccess.png)

See [Managing Access](../creating-a-frag-order/managing-access).

## Collaborators

Frag Orders can now have more than one administrator. Owners can add **collaborators** — Discord users who can co-administer the Frag Order, doing everything the owner can except deleting it, changing its Discord server, or managing collaborators. Add them from the Owner card on the Access tab; Frag Orders shared with you appear under a **Shared with me** tab on your Frag Orders list.

See [Managing Access](../creating-a-frag-order/managing-access#collaborators).

## Pilot Signups

Pilots can now sign up for specific slots directly from the publish. Owners and Editors review each request and approve or deny it. Slot fill counts are tracked per group, and the Pilot Roster kneeboard reflects approved signups automatically.

See [Signups](../creating-a-frag-order/signups).

## Timeline Editor

A visual Gantt-style timeline for the whole package. Place push times, MEZ penetration events, PET windows, VUL blocks, refueling windows, and loiter events against a shared Zulu time axis. Built for multi-flight package coordination where timing relationships matter.

![Timeline Editor showing a multi-flight package](/img/timeline_overview.png)

See [Timeline](../planning/timeline).

## Redesigned Map

The map is now built on a more capable engine with support for:

- **3D globe view** with terrain shading and domed threat rings
- **MGRS grid overlay**
- **Drawing tools** — lines, rectangles, circles, polygons, text annotations, and NATO MILSYM icon markers
- **Per-layer visibility controls** for OPFOR, vehicles, drawings, threat rings, and more
- **New map tile pipeline** — theater tiles are generated from an in-house pipeline, producing sharper, more accurate terrain for all supported DCS theaters

![3D map view with terrain and threat rings](/img/map_3d.png)

See [Map Overview](../the-map/map-overview) and [Drawing Tools](../the-map/drawing-tools).

## Redesigned Kneeboards

The data card and route card have been substantially improved. The data card now includes the full flight roster, all waypoints with leg distances and cumulative TOT, and two radio columns. The route card uses the same map engine as the planning workspace.

![Route card kneeboard](/img/knee_route.png)

See [Kneeboards](../kneeboards).

## Data Transfer Cartridges

Create, upload, assign, and edit DTCs for the F-16C, F/A-18C, F-14B(U), and AH-64D. Send shared map drawings and planned routes to cartridges, inspect section-specific maps, and coordinate route timing in the Timeline. Editors can change radio presets and import controls, copy partitions or selected sections between cartridges of the same airframe, and rename cartridges while preserving assignments and export targets.

Saved cartridge downloads include planned exports when the build succeeds, with warnings for content that will not fit. DTC Route Cards and Point Lists provide printable cockpit references.

See [Data Transfer Cartridges](../planning/dtcs), [Timeline](../planning/timeline#dtc-routes), and [Kneeboards](../kneeboards#dtc-kneeboards).

## Hornet CAP Tracks and Corridors

Inspect Hornet CAP tracks and corridors on the map and in the DTC inspector. Export shared line drawings as CAP tracks or corridors, with adjustable CAP diameter and turn direction. The **CAP & Corridors** tab previews stored entries and pending exports before you download.

See [Hornet CAP Tracks and Corridors](../planning/dtcs#hornet-cap-tracks-and-corridors).

## Text Annotations

Add multiline text to the map with configurable color, size, outline, and rotation. Text keeps its display size as you zoom, can be saved in Drawing Sets, and exports to the DCS F10 map as native text boxes.

See [Text Annotations](../the-map/drawing-tools#text-annotations).

## Personal Drawing Visibility

Show or hide individual drawings and routes without changing anyone else's view. Search the visibility list or toggle all matching items; your choices are saved per publish in this browser.

See [Hiding Individual Drawings and Routes](../the-map/map-overview#hiding-individual-drawings-and-routes).

## Drawing Library

Save a mission's map drawings as a reusable set and import them into future missions on the same theater. Recurring annotations — SAM rings, ingress corridors, kill boxes — can be drawn once and reused. Imports are collision-aware: identical drawings already present are skipped, so re-importing or importing an overlapping set never creates duplicates.

See [Drawing Library](../the-map/drawing-library).
